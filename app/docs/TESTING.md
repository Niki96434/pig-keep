# Тестирование

## Особенности тестирования

### Backend:

Для изоляции интеграционных тестов используется отдельная, чистая тестовая БД.\n
Чтобы у тестовой бд была всегда актуальная структура в соответствии с закоммиченными\n миграциями, требуется воспользоваться командой:

```
npx drizzle-kit migrate
```

Для запуска интеграционных тестов проверки API с тестовой БД:

```
npm run test:api
```

### Frontend:

При создании тестов для кастомных хуков каждый queryClient создавался заново\n
для изоляции кэша и параллельного выполнения без зависимости от глобального инстанса.

## Автоматическими тестами покрыто:

- тестирование бэкенд API(api.spec.ts)
- проверка открытия/закрытия формы при клике, валидация полей формы (NoteForm.spec.tsx)
- проверка отображения списка заметок, проверка на серверную ошибку при выводе списка (NoteList.spec.tsx)
