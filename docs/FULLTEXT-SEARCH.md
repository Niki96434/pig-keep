# Полнотекстовый поиск

В механизм полнотекстового поиска входит подготовка данных(индексация) и поиск(сам процесс извлечения данных)

## Полнотекстовая индексация

Она включает в себя следующие операции:

1. Разбор документов(текстовое поле в строке таблицы/сочетание полей в разных таблицах) на фрагменты - слова, числа, словосочетания, а точнее подстроки текста в полях таблиц. Эту операцию выполняет стандартный анализатор в PG.
2. Преобразование фрагментов в лексемы: на этом этапе создаются словоформы из похожих слов - у них отсекаются окончания, их приводят к нижнему регистру, исключаются стоп-слова(очень распространенные слова, что искать их нет смысла), таким образом лексемы имеют наибольшую ценность для индексации и поиска, в отличие от фрагментов. Эта операция происходит с помощью словарей в PG.
3. Хранение документов в форме, уже готовой для поиска. Например, в виде отсортированного массива из лексем(с положением лексем для ранжирования по близости - чтобы документ, в котором слова запроса расположены «плотнее», получал более высокий ранг, чем документ с разбросанными словами)
