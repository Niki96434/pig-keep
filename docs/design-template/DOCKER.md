# Руководство по работе с Docker

В проекте используется современная спецификация `docker compose` для оркестрации локального окружения, состоящего из приложения и базы данных PostgreSQL.

## tsconfig.prod.json
Для транспиляции из ts в js для того, чтобы контейнер был чистый и тонкий, был создан отдельный файл
`tsconfig.build.json`.
