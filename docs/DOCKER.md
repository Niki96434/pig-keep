# Docker

Приложение с заметками целенаправленно создано как local-hosted.\

## Особенности реализации

### docker compose для боевой базы данных
- создан именованный том `postgres_data` для постоянных данных, чтобы избавиться от эфемерности контейнера
- прокинуты данные для подключения из .env файла
