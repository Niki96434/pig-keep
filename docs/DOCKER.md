# Docker

Приложение с заметками целенаправленно создано как local-hosted.\

## Особенности реализации

### docker compose для боевой и тестовой баз данных
- создан именованный том `postgres_data` для постоянных данных, чтобы избавиться от эфемерности контейнера, для тестовой базы использован tmpfs(temporary file system), чтобы ни в контейнере, ни на хосте не сохранялись данные тестов
- прокинуты данные для подключения из .env файла
